# 🚜 Hofsimulator

Einfacher Landwirtschafts-Simulator von oben für Android: Felder kaufen, grubbern, säen, düngen, ernten und verkaufen – mit Helfern, Maschinen und Ställen. Jede neue Welt wird zufällig erzeugt.
